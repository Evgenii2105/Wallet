Для построения приложения была применена архитектура VIPER для каждого модуля. Архитектура была выбрана для удобства расширения функционала приложения и тестируемости кода. Открытие главного экрана осуществляется путем замены корневого контроллера в зависимости от того, выполнен ли вход пользователем. Для хранения состояния авторизации используется UserDefaults. Цвета из дизайна вынесены в отдельную структуру для удобства использования. Верстка осуществлена при помощи SnapKit. Для работы с данными бекенда реализованы две сущности: одна отправляет запрос на сервер, а вторая трансформирует полученные данные. Для отображения алертов создана отдельная сущность.
