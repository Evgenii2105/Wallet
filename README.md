Для построения приложения была использована архитектура VIPER для каждого модуля. Архитектура была выбрана с целью удобства расширения функционала приложения и тестируемости кода.
Открытие главного экрана осуществляется при помощи подмены рутового контроллера в зависимости от залогинился пользователь или нет. 
Для хранения состояния авторизации пользователя испольуется UserDefaults.
Цвета из дизайна приложения были добавлены в отдельную сущность для удобства использования.
Верстка осуществлена при помощи SnapKit.
Для получения данных из бекенда были реализованы две сущности: одна отправляет запрос на сервер, а вторая преобразует необходимые данные.
Для показа Алертов была создана отдельная сущность для удобства применения.
